# 前台全站換皮設計規範

## 1. Visual Theme & Atmosphere
沿用使用者同意的自訂 Sports Editorial：NBL 的淺底卡片與橘色焦點，配合 Sofascore 的資訊密度。字型採 Noto Sans TC 與 Barlow Condensed。以每週相聚打球的親和感為主，無需大量新聞照片維持頁面。使用者已驗收首頁樣張，延伸至所有前台頁面；資料讀取及既有功能保留。

## 2. Color Palette & Roles
CSS variables 定義 orange 500/600/700（主動作）、green 500/700（勝績）、neutral 50–900。隊伍色保留紅黑藍綠黃白語意；所有元件透過 token 取值。主色 #ed571b，文字 #202622，背景 #f4f5f2，白卡 #fff，細線 #e4e6e1。

## 3. Typography Rules
Noto Sans TC：正文 14/16；人名至少18px，保留原本較大字級，黑隊700、其他隊500；標題 20/24，400/500/700。Barlow Condensed：英文標籤、比分、主標 36–64，700。標題行高 1.1–1.25，正文 1.6，小字 1.5；大字收緊，小字不收。數字使用 tabular-nums。

## 4. Component Stylings
卡片白底，細描邊，圓角 12；賽程白底隊徽、開賽狀態。按鈕 44px 以上，主動作橘色，hover 深一階，active 深兩階，focus-visible 3px outline，disabled 淺灰。頁籤 aria-selected；正式互動含比賽週切換、數據項目切換、手機選單；已完賽場次連入既有單場對戰數據頁。圖示採一致線條 SVG。無對應頁面功能以站內既有官方頁連結提供。

## 5. Layout Principles
視覺主次：第一主角「每週六，球場見」品牌主視覺；第二本週賽程；第三清楚的戰績與球員數據。中性階梯區分文字；8pt spacing（4/8/12/16/24/32/48/64）。桌機最大 1280px，主內容與戰績側欄比 2.15:1；手機邊距 16px。主區塊間 32px。首頁表格固定布局，名次、隊伍、戰績與勝率設明確欄寬；保留完整戰績頁的近況與連勝敗。

## 6. Depth & Elevation
一般卡片不加厚陰影；懸浮導覽和彈窗使用 shadow-md token。主視覺以暗色遮罩確保白字辨識。z-index：header 10、bottom-nav 20、dialog top layer。

## 7. Do's & Don'ts
Do：數字右對齊；保留手機優先賽程；主次明確；觸控範圍至少44px。
Don't：大圖壓掉賽程；假造即時分數；把示意資料說成最新資訊；改正式站程式或既有未提交修改。

## 8. Responsive Behavior
單樹：桌機並欄、手機依賽程→主視覺→戰績→個人數據→龍虎榜排序。CSS grid areas 在 960px 以上展開；導覽在寬度足夠時顯示文字列。賽事列 horizontal scroll-snap；手機保留下一張露頭。驗證 375/390/768/1440px，頁面本身不可橫向溢出。prefers-reduced-motion 停用平滑捲動。圖片已下載到本地。

## 9. Agent Prompt Guide
全站共用外觀由 site-theme.css 與 shared-app.js 管理，首頁獨有樣式由 home.css 管理；保留原 shared-styles.css 的功能布局。正式頁面仍透過既有 api 抽象層讀取資料，不引用預覽 data.js。首頁加入品牌照片；其餘頁以明確的頁標題與各自功能為主，不重複大型照片。12 頁包含首頁、賽程、戰績、對戰數據、領先榜、球員名單、龍虎榜、輪值、數據統計、歷史賽季、名人堂、公告。歷史及公告等原本未公開於導覽的頁面只套樣式，不新增公開入口。資料缺少時顯示既有空狀態，不補造數字。

對戰數據卡片追加：手機/桌機同樹；首行場次＋右側展開，次行「主隊名｜主隊比分｜VS｜客隊比分｜客隊名」，隊伍兩外側、比分在VS左右鏡像對齊，皇冠不改欄位軸。待賽雙側—、狀態集中，真0照顯示；沿用既有字體/配色/間距token及球員表格。
